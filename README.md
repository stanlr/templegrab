# Temple Grab

An endless-runner game where you pick one of four runners, then sprint through temple ruins, collect USDC coins worth 0.01 each, and dodge stones, pillars and low beams. It is just for fun: coins add to a play USDC balance saved in your browser, with no wallet or real tokens involved.

Built with [Arc Studio](https://studio.arc.io)

## Tech stack

React, TypeScript, Vite, Tailwind CSS, HTML canvas.

## Development

Prerequisites: [Bun](https://bun.sh).

```bash
bun install
bun run dev
```

Other scripts: `bun run check` (lint and typecheck).

### Controls

- Keyboard: arrow keys or WASD to switch lanes, jump (up, space) and slide (down). Enter starts a run.
- Touch: swipe left, right, up or down. Tap to jump.

### Environment variables

None.
